# Genesis

Genesis is an AI Operating Platform by WolfX BI built with Next.js 15, React, TypeScript, Tailwind CSS, and the App Router.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the application.

## Routes

- `/login`
- `/dashboard`
- `/chat`
- `/documents`
- `/knowledge-base`
- `/business-intelligence`
- `/agents`
- `/automation`
- `/languages`
- `/profile`
- `/settings`

No APIs are connected yet; all data is presentation-ready mock content.
